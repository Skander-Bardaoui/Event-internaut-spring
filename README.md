## Overview

A Spring Boot REST API for managing events and participants. Built with Spring Data JPA, MySQL, Lombok and springdoc OpenAPI, following a clean controller-service-repository structure.

## Highlights

- Event CRUD endpoints
- Spring Data JPA repositories and services
- MySQL persistence
- OpenAPI / Swagger documentation
- Lombok-based models

## Getting started

**Prerequisites:** JDK 17+, MySQL and Maven.

```bash
./mvnw spring-boot:run
```
